# T4 Chord Trainer

A typing tutor for the [Twiddler 4](https://www.mytwiddler.com/) one-handed chording keyboard. It ships with
Alex Bravo's **Backspice** layout and can load any other layout.

You type on your real Twiddler. The page draws the device with each key's output printed on it, and lights up
the keys for the next character. Hints fade out as you learn.

## Running it

No build step and no server needed:

- open `index.html` in a browser, or
- serve the folder from any static host (GitHub Pages works as-is), or
- run `node tools/build.mjs` and open `dist/twiddler-trainer.html`, a single self-contained file.

Progress, settings and your own layouts are stored in the browser's `localStorage`.

## What's in it

**Practice**
- A lesson plan generated from the active layout. For Backspice that is:
  - one-key letters first (`e t a o i`, then `n s h r`)
  - two-key letters three at a time
  - capitals, punctuation, numbers and symbols
  - the multi-character "shortcut" chords such as `the`, `ing` and `and`
- Practice text is real English words limited to the letters you have learned so far, padded with short letter
  groups when there aren't enough words yet.
- Hints can show always, after a 1.5 s pause, only after a mistake, or never.
- Mistakes don't advance the cursor. The chord you should have pressed stays lit until you get it right.
- Live speed and accuracy. A lesson counts as complete after a round at 95% accuracy or better.
- Per-character accuracy and timing feed a **Weak spots** drill.
- **Custom text**: paste anything and type it.
- Shortcut-chord detection: characters that arrive within 35 ms of each other came from a single
  multi-character chord. They are underlined and counted.

**Explore**
- Click keys to hold them. Every other key then shows what adding it would type, like the anchor grids on the
  Backspice cheat sheet. Thumb buttons work too.
- Type on the Twiddler and the chord for each character, or each multi-character burst, lights up.
- A searchable, filterable table of every chord in the layout.

**Layouts**
- Edit layouts as text, duplicate them, or make a mirrored (left/right swapped) copy.
- Import from:
  - this app's text format
  - Twiddler Tuner CSV exports
  - the JSON used by the official typing tutor
  - Twiddler 3 binary `.cfg` files (format v5)

## Orientation

The diagram draws finger columns **R · M · L** from left to right by default. This matches the Backspice
cheat sheet, which is drawn for the left hand. Thumb buttons are drawn T1–T4 (N, A, C, S) left to right.
**Mirror finger keys** and **Mirror thumb buttons** flip either one. The note under the device tells you which
key to press to check the drawing against your hand.

## Layout text format

```
# name: My layout
# One chord per line: CHORD = OUTPUT
OOMO = t              # classic notation: rows 1-4 (index..pinky), each L, M, R or O
S OLLO = In           # thumb keys N A C S = T1 T2 T3 T4
T4 F1L F3M = &        # Twiddler 4 notation also works
F0M = <Enter>         # row 0 = the three mini buttons
MOOO = <Space>
N LOOO = <Cmd+s>      # special keys and shortcuts in angle brackets
LLOR = \<             # \< types "<", \\ types "\"
```

Capital letters don't need their own chords. The Twiddler sends Shift (T4) plus the lowercase chord, and the
trainer assumes the same.

## Notes and limits

- **Thumb buttons.** The Twiddler 4 numbers its thumb buttons T1–T4 left to right. The classic layout notation
  calls them N, A, C, S (Num, Alt, Ctrl, Shift). The trainer maps them in that order.
- **Twiddler 4 `.cfg` files.** These binary files (format v7) are not documented, so they can't be imported
  directly. Paste the chord list as text, or export it as CSV or JSON, instead.
- **Backspice source.** The built-in layout is converted from `config v5 - for Twiddler 3/twiddler.cfg` in
  [AlexBravo/Twiddler](https://github.com/AlexBravo/Twiddler) by `tools/v5tolayout.py`. It was checked against
  the `Backspice2 cheat sheet.txt` in the same repository. Two kinds of chords were removed:
  - personal macros (name, email, phone number)
  - four Alt+Shift text-selection macros
- **Word list.** The 2,000 most common lowercase words across ten public-domain Project Gutenberg novels,
  built with `tools/wordlist.py`.

## Development

```
node tools/build.mjs      # regenerate js/layouts.js from layouts/*.layout and build dist/
node --test tests/*.test.mjs
```

Code lives in `js/`:

| File | What it does |
| --- | --- |
| `core.js` | Layout model, chord notation, importers |
| `lessons.js` | Lesson plan and text generation |
| `diagram.js` | The device drawing |
| `app.js` | Practice view and app shell |
| `explore.js` | Explore view |
| `layouts-view.js` | Layouts view |

Edit `layouts/*.layout` rather than `js/layouts.js`, which is generated by `tools/build.mjs`.
