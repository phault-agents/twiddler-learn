    Add a layout

    Load a file or paste a chord list. Accepted: this app's text format, Twiddler Tuner CSV exports, the official typing tutor's JSON, and Twiddler 3 binary .cfg files.

    Text format 
    # name: My layout
# One chord per line: CHORD = OUTPUT
OOMO = t            # classic: rows 1-4, L M R or O
S OLLO = In         # thumb keys N A C S = T1 T2 T3 T4
T4 F1L F3M = &      # Twiddler 4 notation
F0M = <Enter>       # row 0 = mini buttons
MOOO = <Space>
N LOOO = <Cmd+s>     # special keys and shortcuts
LLOR = \<            # \< types "<", \\ types "\"

    Lines starting with # are comments. In a classic chord, L, M and R are the columns as the Twiddler Tuner names them.
